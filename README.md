
# Simple Interest Calculator

## Project Overview
A simple web application that calculates simple interest and the total amount using the principal, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Enter principal amount, interest rate, and time.
- Calculate simple interest.
- Calculate the total amount.
- Validate input values.
- Reset the calculator.

## Example
- Principal: 10000
- Rate: 5%
- Time: 2 years
- Simple Interest: 1000
- Total Amount: 11000

## How to Run
1. Download the project ZIP file.
2. Extract the files.
3. Open index.html in a web browser.
4. Enter the values and click Calculate Interest.

## Purpose
This project demonstrates a simple interest calculation using HTML, CSS, and JavaScript.
