# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for your interest in improving the Simple Interest Calculator project. Your feedback and contributions can help make this project better.

## How to Contribute

- Report bugs or unexpected behavior.
- Suggest new features or improvements.
- Improve documentation.
- Submit bug fixes and code enhancements.

Please describe your changes clearly when submitting a contribution.
